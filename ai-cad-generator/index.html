Key College Viva Voce Defense Questions & Answers

Q1: How does the system communicate with SolidWorks?

SolidWorks provides a Windows COM/ActiveX Type Library. In Python, the pywin32 (win32com.client) module acquires the SldWorks.Application dispatch interface to programmatically manipulate sketches, extrusions, cuts, and patterns.

Q2: Why not replace SolidWorks with an AI neural model like Point-E?

Neural point clouds lack engineering parametric features, exact tolerances, sketch constraints, and machinability. Our system acts as an automation layer on top of SolidWorks, ensuring all output parts are 100% parametric, editable in SolidWorks, and manufacturing-ready.

Q3: How are invalid dimensions prevented?

A relational geometric validator runs before dispatch (e.g. checking that Gear Bore < Outer Diameter, Wall Thickness > 0, and Pitch circle diameters align with tooth module formulas).

Project Abstract & Technical Specifications

Project Title: AI-Based Automated CAD Model Generation System Using SolidWorks API

Objective: Eliminate repetitive manual CAD modeling for standardized mechanical components by automating the design-to-CAD pipeline through natural language requirement parsing and API-driven SolidWorks geometry synthesis.

  • Parametric Rules & Mechanical Constraint Checker
  • CSG SolidWorks COM Dispatcher (SldWorks.Application)
  • WebGL Three.js Interactive 3D Inspection Viewer
  • Direct STL / SLDPRT / STEP Exporters
